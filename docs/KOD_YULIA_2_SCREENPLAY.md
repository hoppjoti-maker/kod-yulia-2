## Что это чинит в ролике

| Было (размазня) | Стало (сценарий) |
|---|---|
| 18 с английского листа Age/Height | 12 с инвентаря, потом хлеб — конфликт «объект / человек» |
| петля из 6 стоп-кадров | 12 сцен, причина идти в следующую |
| нет диалогов | Пакет / Юля / Элиас / YU-9 / касса — цели разные |
| нет сюжета | канал лезет в рот → жест выдаёт её Элиасу → двойник снимает щит → «Нет» днём → окно рвёт канал → имя остаётся |
| turnaround как HUD | студия = взгляд ядра; живая Юля ест и врёт задержке |
| две женщины в пальто без роли | Юля ↔ YU-9 (инвентарь) и отдельно Элиас (жест) |
| стол лаборатории без ставки | врезка: тело уже списали |
| оранжерея как обои | сбой склейки, камера выбирает ровный век |
| тишина −54 dB | пакет, «Нет», «Юля», «Рот ещё мой» |

Метка на плече, стол, два профиля, крупный план глаз, мокрое пальто — остаются. Английский HUD, `YULIA_MASTER_TURNAROUND`, любой повтор круга — вон.
